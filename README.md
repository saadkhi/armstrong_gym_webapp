# Armstrong Gym Webapp

The application lives in [`armstrong-gym-management-system/`](./armstrong-gym-management-system/).

See **[armstrong-gym-management-system/README.md](./armstrong-gym-management-system/README.md)** for setup, local development, and Vercel deployment instructions.

```bash
cd armstrong-gym-management-system
npm install
cp .env.example .env   # configure NEON_DATABASE_URL + JWT_SECRET
npm run db:init
npm run dev
```
